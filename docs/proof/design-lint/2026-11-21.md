# design-lint 0.3.0 proof: chykalophia.com homepage, 2026-11-21

Real run of `hallmark-lint` and impeccable 4.8.2 through `lint-filter.mjs` on the live homepage
(https://www.chykalophia.com/), in a cloud container running as root. No site was changed.

## Setup

`.cklph/design-exceptions.json` with the site's brand choices: impeccable `kicker-above-heading`,
`hero-eyebrow-chip` and `italic-serif-display`; Hallmark gates 54, 67 and 38i. Each has a reason.

## Results

| Run | Check | Taste | Excused | Time |
|---|---|---|---|---|
| `hallmark-lint` (first run, fetch and install included) | 10 | 26 | 0 | 19s |
| impeccable 1440x900 | 31 | 0 | 17 | ~11s |
| impeccable 768x1024 | 35 | 0 | 15 | ~11s |

Hallmark's URL run didn't fire the eyebrow gates on this page, so nothing of its was excused.
Its eyebrow and italic rules fire in source scans, which `design-lint` says not to run.

## Checked by hand

- Hallmark 34, sideways scroll at 768: **real**. `scrollWidth` 805 at a 768 viewport; the tilted
  work columns in the hero stick out. impeccable didn't report it at 1440, 390 or 768.
- Hallmark 44d, hero text 64px from the edge at 1920: **real**. The hero has no capped container.
- Hallmark 26a, focus ring 1.73:1 on "Download the Checklist": **false**. The ring is white on navy.
  Listed as a known false positive in the skill.
- impeccable `line-length` and `cramped-padding` (comparison table): real, small. Hallmark missed them.

## Exit codes

Both runs exited 2 (findings to check). A slop-only impeccable input with the exceptions file exits
0, which `tests/lint-filter.test.mjs` asserts.
