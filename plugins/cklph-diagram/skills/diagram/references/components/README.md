**The composition rule.** One node style, at most two connector treatments, one
elevation step, one radius scale, one ground per diagram — then hold all of them
across the whole set. Mixing without a rule produces mush, and every extra
choice is a legend entry and a thing the reader must remember.

**The test.** Demo 41 puts an untreated diagram beside a treated one with
identical content. If applying a theme does not move the first toward the
second, the theme is not finished.
