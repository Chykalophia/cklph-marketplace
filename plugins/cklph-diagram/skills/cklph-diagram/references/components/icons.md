# Icon system
One grid, one stroke weight, one joint style.

| Token | Value |
|---|---|
| `icon-box` | 24 × 24 |
| `icon-stroke` | 1.8 |
| `icon-joins` | round cap, round join |
| `icon-fill` | none, except 1.3r dots for indicators |

## Rules

- **Mixed icon sources are the most common way a careful diagram goes cheap.**
  One pack, or redraw on the shared grid.
- **Vendor logos are the hard case** — they arrive at different weights and
  cannot be restyled without breaking trademark guidance. Put them in a neutral
  container so the container carries the consistency.
- An icon is never the only label. Pair it with text or it fails for anyone who
  does not already know the glyph.
