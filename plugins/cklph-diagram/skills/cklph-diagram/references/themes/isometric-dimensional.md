# Isometric Dimensional

30° extruded blocks with three-tone face shading and ground shadows. The one that stops the scroll.

**Reach for it when:** Infrastructure overviews, launch graphics, conference slides.

> **Watch out:** Cannot be scanned linearly and gets hard to read as complexity rises. Overview only.

This theme is a set of choices from [`../components/`](../components/). Those
are the parts; this is one assembly of them.
