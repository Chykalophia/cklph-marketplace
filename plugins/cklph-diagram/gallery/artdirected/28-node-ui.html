Node UI Canvas

It looks like a running application, which implies the system is real.

Card, header, ports, pills. Nodes are cards with a tinted header strip and a key/value body; port handles are small circles on the edge; bezier connectors leave the ports; a dot grid and a minimap complete the illusion of a live canvas.

Watch out: Borrowed product chrome sets an expectation. A minimap on a static PNG is a small lie — keep it only where the interactivity is real or the diagram is obviously a still.
