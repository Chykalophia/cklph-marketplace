Fix 3 · Elevation Stack

One shadow looks cheap. Four layers, each with a job, looks built.

Border, ambient, distance, inner ring. Built up one layer at a time so you can see each contribution: a 1px spread makes the edge, a 2px blur is ambient light, an 8px blur handles distance, and a near-white inner ring makes the card glow from within.

Watch out: Elevation should clarify layering, not create a floating-card look. Do not nest elevated surfaces without a reason.
