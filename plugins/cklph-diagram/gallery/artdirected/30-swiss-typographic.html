Swiss Typographic

No boxes at all. Rules, numerals and type do the structural work.

Tabular numerals and hairline rules. Numbered sections, one accent, flush-left everything, and metrics set in tabular figures so the columns align. It reads expensive because it reads like a printed annual report.

Watch out: Only works when the content is genuinely tabular or sequential. Forcing a branching system into this format loses the branches.
