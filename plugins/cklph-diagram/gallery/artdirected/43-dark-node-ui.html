Dark Node UI

Linear's restraint with React Flow's node grammar.

Where the two families overlap. Near-black ground, hairline borders, one indigo accent and tight mono tracking from the first; card headers, key/value bodies and port handles from the second. They share a grammar, so the combination is clean.

Watch out: Dark plus hairline borders is fragile in print and on projectors. Keep a light variant of any theme built on this.
