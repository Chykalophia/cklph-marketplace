Network Topology

Actual networking grammar — bundles, standby paths, VLANs.

Line style carries protocol meaning. Two parallel strokes is a LAG bundle. Dashed is standby, carrying no traffic. A coloured header strip types the device. None of this needs a key for a network engineer, and all of it is in the legend anyway.

Watch out: Borrowed conventions only help people who know them. Keep the legend even when the audience 'should' know — the cost is one strip, the failure is silent.
